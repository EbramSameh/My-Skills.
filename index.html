CorroBot: the robot and the C++ behind it

A tracked inspection robot built to find rust. I wired the electronics, built the drive system and wrote the firmware that makes it move, see and stop safely.

Robotics

Camera, motor driver, tilt servo, flash LED, DHT climate sensor and battery power on a tracked chassis. It drives from a control page on any phone or laptop.

C++

The firmware serves the control page, streams video over the robot's own Wi-Fi, takes drive commands and AI targets over HTTP and WebSocket, and runs motors and servo with PWM.

Fail-safe

No fresh target for 350 ms: stop. Confidence under 0.55: stop. No command for 700 ms: motors stop. And there is an emergency stop endpoint.

Corrobot-final.ino, the safety check that runs before the robot steers

bool stale = (now - lastTargetUpdateMs
              > TARGET_TIMEOUT_MS);
bool lowConfidence =
    (currentTarget.confidence < MIN_CONFIDENCE);

if (stale || !currentTarget.detected
    || lowConfidence) {
  stopRobot();
  return;
}

CorroBot AI: a model that sees rust

My vision model looks at the robot's camera feed, outlines rust, picks a target and tells the robot where to go. These are my real tests: I held rust photos up to the robot's camera.

  1. CameraFrames stream in from the robot.
  2. SegmentDeepLab v3 (ResNet-50) marks every rust pixel.
  3. TargetRust patches are found and the best one is chosen.
  4. SteerPosition, size and confidence go to the robot every 150 ms.
  5. ScoreRust plus climate data become a risk index.
My first model wasn't good enough.

So I added augmentation and improved the annotation coverage, and kept going until the model I run now, v3, worked. Built with PyTorch and OpenCV.

CRI = 0.4375·R + 0.375·H + 0.1875·T

R is rust coverage. H is time-of-wetness, from ISO 9223. T is a temperature term that peaks at 10 °C. I swapped a naive "hotter is worse" formula for this one because it follows the standard.

rust_tracker.py, the risk score

R = coverage * 100.0
H = float(np.clip(tow * 100.0, 0.0, 100.0))
T = float(np.clip(100.0 * math.exp(
    temperature_severity_factor(temp)), 0.0, 100.0))

cri = (CRI_WEIGHT_R * R + CRI_WEIGHT_H * H
       + CRI_WEIGHT_T * T)

The script starts in display-only mode and never drives the robot until I switch control on, so every change is checked on screen first.
